# templates

Copy-and-fill starting points. Rules for every field live in [GOVERNANCE.md](../GOVERNANCE.md); allowed values live in [TAGS.md](../TAGS.md).

| File | Use for |
|---|---|
| `header.R` | R scripts and functions |
| `header.py` | Python modules (header is the module docstring) |
| `header.sql` | SQL objects and queries |
| `header.bas` | VBA modules, classes (.cls), and forms (.frm) |
| `header.vb` | VSTO add-ins in VB.NET |
| `header.cs` | VSTO add-ins in C# |
| `header.html` | HTML pages |
| `readme-code-object.md` | README co-located with each code object |
| `readme-folder.md` | README for language and topic folders |
